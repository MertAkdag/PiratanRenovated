# Piratan

An online multiplayer pirate game for mobile. You sail your own ship on a shared sea, fight other players and NPC ships with cannon volleys, repair under fire and collect treasure chests. Built with [mamooo66](https://github.com/mamooo66).

This is the reworked version (2023). Development has stopped.

## Systems

- Real-time multiplayer with Mirror.
- Ship combat: target lock, cannon count and cooldown per ship, damage, sinking, repair.
- NPC ships, treasure chests, rewards and quests.
- Accounts with LootLocker (the first version used Firebase).
- Multi-language UI.

## Tech

Unity 2021.3 · C# · Mirror · LootLocker · Firebase · Figma
